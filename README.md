# Serrana Local Connect

Crie um site web moderno e responsivo para o projeto Serrana Express.



Objetivo:

O site será uma vitrine digital de produtos, lojas e serviços locais. Não terá pagamento dentro do site. O cliente apenas encontra produtos, vê informações e clica para falar com a loja pelo WhatsApp ou acessar o link do produto/loja.



Estilo visual:

- Aparência moderna, profissional e chamativa

- Cores principais: laranja, branco e detalhes escuros

- Visual parecido com marketplace, mas com identidade local

- Layout limpo, rápido e fácil de usar

- Design responsivo para celular e computador



Páginas principais:

1. Página inicial

- Banner principal com chamada: “Encontre produtos e serviços da sua cidade em um só lugar”

- Barra de pesquisa

- Categorias de produtos

- Destaques de lojas

- Produtos em destaque

- Serviços locais em destaque



2. Página de categorias

- Lista de categorias como:

  Mercado

  Moda

  Eletrônicos

  Beleza

  Casa

  Ferramentas

  Serviços

  Restaurantes

  Farmácia

  Automotivo



3. Página de produto

Cada produto deve mostrar:

- Foto

- Nome do produto

- Preço

- Nome da loja

- Descrição

- Categoria

- Botão “Falar com a loja no WhatsApp”

- Botão “Ver loja”

- Botão opcional “Acessar link do produto”



4. Página da loja

Cada loja deve ter:

- Logo

- Nome

- Descrição

- Endereço opcional

- WhatsApp

- Instagram

- Lista de produtos cadastrados

- Botão “Chamar no WhatsApp”



5. Painel administrativo simples

Criar uma área protegida para o administrador cadastrar, editar e excluir:

- Lojas

- Produtos

- Categorias

- Serviços

- Banners da página inicial



Campos do produto:

- Nome

- Foto

- Preço

- Descrição

- Categoria

- Loja

- Link externo opcional

- WhatsApp da loja

- Produto em destaque: sim/não



Campos da loja:

- Nome da loja

- Logo

- Banner

- Descrição

- Categoria

- WhatsApp

- Instagram

- Endereço opcional

- Loja em destaque: sim/não



Funcionalidades:

- Pesquisa por nome do produto, loja ou categoria

- Filtro por categoria

- Cards de produtos bonitos e organizados

- Botões chamativos para WhatsApp

- Site rápido e fácil de atualizar

- Preparar estrutura para futuramente conectar com banco de dados como Supabase ou Firebase



Importante:

- O cliente não precisa criar conta

- Não terá carrinho

- Não terá pagamento online

- O foco é vitrine, divulgação e contato direto com a loja

- O administrador deve conseguir editar tudo de forma simples

- Criar dados de exemplo com lojas e produtos fictícios

- Deixar o projeto pronto para publicação
